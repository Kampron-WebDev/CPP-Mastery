# Lesson 59: Capstone Projects ⭐ NEW

> **In one sentence:** You become a developer by **building complete programs**: designing them,
> getting stuck, debugging, and finishing. These projects combine everything in the course.

Exercises teach single skills. Projects teach the skill employers actually pay for: **turning a vague idea into working, maintainable software.**

---

## 🧭 How to work on a project (like a professional)

1. **Read the spec.** Write down questions and decide the answers yourself (you're the engineer now).
2. **Design on paper first:** which classes? Who owns what? What are the files? Sketch it.
3. **Build in milestones.** Each milestone must compile, run and be *committed* (Lesson 60: Git) before the next.
4. **Test as you go:** a small test file, or at least a list of manual test cases with expected results.
5. **Review your own code** with the checklist from Lesson 55.
6. **Only then** compare with the reference solution (where one exists). Different is fine; *understand* the differences.
